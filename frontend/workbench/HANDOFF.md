## 启动（Windows Edge）

解压 ZIP，进入 freight-agent-workbench 目录，运行：

    py -m http.server 4173 --bind 127.0.0.1 --directory dist

若没有 py，使用 python 替代。Edge 打开 http://localhost:4173 。无需 npm 安装。Node 环境下运行 npm test 可复现现有逻辑测试。请使用独立测试浏览器配置、单标签及仅合成数据，避免与已有 localhost:4173 的 localStorage 混用。无公网预览；不需要发布即可验收。
