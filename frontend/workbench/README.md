# FreightPilot · 货代 Agent 参赛与报价工作台

Sites 静态应用，中文界面，浏览器本地数据存储。适合在 Mac 本机报价系统基础上演示、整理案例和持续更新。

## 本地运行

在此目录运行 `npm start`，访问 `http://localhost:4173`。无需安装依赖。运行测试：`npm test`。

## 功能

- 工作台、客户询价和多维筛选、明确字段提取与人工修正；缺失、冲突、范围或单件数量不自动填值。
- 海运、空运、国际快递、专线、空派、海派条件匹配；保留可直接计算、需人工询价、不支持等区分。
- JSON 运价规则导入；文件/工作表/单元格/版本/SHA、原文件 SHA、费用、币种与待确认项追踪。
- 分类确认 → 锁定快照并申请一次审批 → 真人点击批准或拒绝 → 显示已锁定的预计算试算结果；拒绝停止，重启不会重置。
- 客户确认与本地订单登记、物流节点和当前位置、异常标记与解决、审计及修改日志。
- 七步比赛讲解、六主题销售训练、正确率与错题记录。
- 案例复制，报价说明、复盘与参赛材料复制/Markdown 导出，浏览器打印 PDF，完整 JSON 备份恢复。

## 明确边界

本版没有连接实际运价 API、承运商、实时定位、共享数据库或多人账号。价格均由演示 JSON 或用户整理并核验的 JSON 提供。演示不是实际报价，不应向客户作为业务承诺发送。

本地操作人是记录标签，不是认证身份。单次审批防止正常界面中的重复操作；localStorage 可以被设备持有人修改，因此不能作为防恶意篡改或跨 Agent 可信授权机制。接真实业务前需要后端认证、服务端状态机、持久化幂等、不可覆盖审计、客户确认凭据与规则版本有效期。浏览器多标签和多用户协作不在首版支持范围内，请使用一个标签操作并定期导出。

提取器为保守规则实现，不是已接入大模型的语义解析器。优先使用界面中的带标签格式；未匹配内容需人工补充。币种分别列示，不做猜测汇率换算。贸易术语训练是流程训练，不代替专业合规建议。

## 运价导入

来源库下载模板。每条规则需指定适用国家、货类、服务需求、重量/体积上限、时效、币种、计费单位、附加费与待确认项。真实来源需 `originalFile`、64位 `originalSha`、`sheet`、`cell`、`version`。可用原文件哈希工具核对原 Excel/PDF 的 SHA。导入后均为待核验，人工核验且待确认项为空才允许计算。已锁定案例复制规则快照，不随来源库变化。
