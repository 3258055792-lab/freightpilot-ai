## 来源说明问题 R1

优先级 P1，影响报价来源可信度。现有 52 项回归仍通过，补充 CLI 检查复现了来源说明与当前文件不一致。

复现方式为对上述固定夹具执行 `freight_calculate`，核对 `unresolved` 与来源单元格。

| CLI 待确认说明 | 本次源文件实际内容 |
|---|---|
| B19 对公转账 3% | B19 只有不足 1 CBM 按 1 CBM、其他费用待确认 |
| B19/B24 超品名费 20 USD 与 50 USD | B19 没有这些金额，B24 为空 |
| B20/B22 单件超重、大件及超长费 | B20、B22 均为空 |
| B23 打木箱 400 CNY/万 | B23 只有 800 CNY/票、100 CNY/件、60 CNY/件 |

代码证据位于 `prototype/freight_tools.py` 的 `calculate()`，`unresolved` 列表直接写入了上述说明。基础运费算术结果不受该问题影响，但 UI 若直接展示这些条目，会把固定说明当成当前源文件证据。

建议 FP-01 在适配时保留通用的待核验提示；带单元格和金额的具体说明应从当前锁定来源读取。修复时补一条针对合成夹具的来源一致性回归。核心文件由集成负责人协调，本轮仅提交复现记录。

FP-01 需交接固定 Sites 预览与源码/构建标识、连接的后端版本、冻结的模拟源文件及 SHA、第二版本夹具、批准和试算记录的核对入口，以及目标浏览器和适用操作范围。没有这些交接材料，五项 UI 结果继续记为待执行。

有效批准次数按同一案例、输入和来源版本核对。日志中被拦截的重复尝试可以保留。拒绝后的新复制案例不能代替原案例拒绝终止检查。
