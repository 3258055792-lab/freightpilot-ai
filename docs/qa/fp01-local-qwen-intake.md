# FP-01 · 在同一案例中识别原文、补料、切换运价并审核

2026-11-22，Mac Chrome，LM Studio 的 qwen3.5-9b-mlx，本机合成测试身份及隔离的 SQLite 库。一次浏览器流程中只新建一个案例。模型负责摘取品名、目的国和运输方式；现有数量解析器核对体积、重量及箱数。页面引用随仓库固定的 SOP-01 v1 §1。

| 步骤 | 输入与操作 | 本机实际结果 |
| --- | --- | --- |
| 识别 | 在新建询价输入「30箱塑料收纳盒从中国海运到巴西，总重400公斤，请报价。」后点「用本地千问识别客户原文」 | 返回塑料收纳盒、巴西、海运、400 kg；体积留空，提示补充整票总体积 |
| 补料 | 原文末尾追加「总体积3立方米。」并再次识别 | 原商品和重量保留，体积为 3，页面提示核对并选表 |
| A · v2 | 选择 A 并保存；申请、批准本版试算；生成草稿；另行申请并批准内部草稿审核 | 2,460.00 USD，保存的审核快照引用同一次计算结果的来源 SHA |
| B · v3 | 改选 B，点击「保存人工修改」，再次试算、审核 | 保存时服务端返回旧审核失效、当前金额为空；新版得到 2,280.00 USD |
| A · v4 | 切回 A，重新试算并申请审核；本次模拟选择拒绝 | 2,460.00 USD，新的审核 ID，待审后转为拒绝；首版批准未复用 |

复测者可使用 README 中的本机启动方式及上述原文。建议用新案例、独立测试数据库，记录候选提交、三个草稿版本及两类授权 ID。金额均为合成基础运费。固定规范的引用覆盖这一询价场景，任意企业文档检索、真实审核人身份及对客发送仍在本轮范围之外。
