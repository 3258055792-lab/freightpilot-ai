模型qwen3.5-9b-mlx；LM Studio本机服务；真实模型非HTTP替身，真实Python子进程与合成数据库。日志包含工具调用和来源，无密钥或客户数据。

- classify.json：输入“合成测试：客户询问塑料收纳盒发往巴西，3CBM、400kg。请调用freight_classify给出候选类别与来源证据，不做试算。”实际完成分类、来源证据及模型总结，10.766秒；模型两轮。
